# Image guide

The playable library includes 28 photographs supplied in the user's `Derm Game Images` folder. Permission to use the images was confirmed by the user. The source pages, photographer names, and public-license details were not supplied, so the credits file identifies this provenance without claiming an open license. Each photograph is an independent teaching image, not a record of its fictional game patient. No Fitzpatrick type is inferred.

The active images are stored in `public/images/cases/` and listed in `src/data/cases/index.json`. Their alt text describes visible morphology and location where visually confirmed. The three AVIF files could not be rendered by the available review tools during this update; their alt text avoids unverified visual details and identifies the supplied diagnosis label. The necrotizing-infection image depicts advanced operative tissue loss and is graphic.

## Adding an image

Inspect the image directly and confirm permission before adding it. Record source URLs, photographer credit, and license terms only when provided or independently verified. Never infer these details from a filename or watermark alone. Avoid personal identifiers; crop only when the change preserves the clinical finding and permission allows adaptation. Describe visible morphology and body site in alt text. Do not infer Fitzpatrick skin type. Keep each supplied teaching photo clearly distinguished from the fictional patient's record.
